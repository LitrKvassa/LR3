# Броуновское движение частиц — метод Монте-Карло
Программа моделирует независимые двумерные броуновские траектории частиц в неограниченной плоскости. Используется дискретизация винеровского процесса с независимыми нормальными приращениями и статистический анализ методом Монте-Карло.

## Особенности и параметры модели, программная реализация

Программа имеет интерфейс в консоли IDE. При запуске программы в консоль IDE выводится меню вида:

            <Меню>
    1. Текущие параметры
    2. Ввод параметров
    3. Расчёт
    4. Выход
    <Ввод>: 

### Пункты меню

- Пункт 1: выводит текущие заданные параметры модели;
- Пункт 2: позволяет поочерёдно ввести собственные параметры для расчёта;
- Пункт 3: запускает расчёт с заданными параметрами или параметрами по умолчанию;
- Пункт 4: завершает работу программы.

## Входные данные
| Параметр | По умолчанию | Значение |
|---|---:|---|
| `N` | 1000 | Число независимых частиц, целое ≥ 1 |
| `t` | 1000 | Число временных шагов, целое ≥ 1 (не физическое время) |
| `dt` | 0.01 | Длительность шага, > 0 |
| `D` | 1.0 | Коэффициент диффузии, > 0 |
| `inter` | 30 | Интервал кадров GIF, мс, целое, ≥ 1 |
| `trail` | 0 | Длина отображаемого следа в шагах, 0 — весь путь |

Полное физическое время (в у.е. времени): `T = t * dt`. При каждом расчёте создаётся новая случайная реализация траекторий частиц.

## Выходные данные
При выборе расчёта автоматически создаётся папка `results` в папке с файлом `LR3.py`. Существующие файлы перезаписываются при следующем расчёте. Выходными данными являются анимация, графики, а также текстовый вывод в консоль положений частиц, значений СКС. 

| Файл | Содержание |
|---|---|
| `animation.gif` | Анимация движений частиц и их следов |
| `trajectories.png` | Полные траектории и конечные положения |
| `histograms.png` | Гистограммы распределения X и Y |
| `msd.png` | СКС моделирования и эталона |

## Ограничения

Модель описывает идеальный свободный двумерный винеровский процесс: без границ, столкновений, межчастичных сил, инерции; параметры не привязаны к конкретному веществу или температуре; генерация случайна.
